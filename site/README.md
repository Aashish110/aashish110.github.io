# Personal Website

This is a static personal website inspired by the calm, typography-led feeling of `raffaello.name`, but with original layout, copy, and visuals.

## Edit These First

- Replace `Your Name`, `YN`, and the title/description text in `index.html`.
- Replace `your.email@example.com` with your real email address.
- Update the GitHub, LinkedIn, and X links in the footer.
- Replace the sample projects and writing entries with your own.
- Swap `assets/personal-hero.png` for your own photo when you have one.

## Publish With GitHub Pages

1. Create a new GitHub repository named `yourusername.github.io`.
2. Upload the contents of this `site` folder to that repository.
3. Commit the files to the `main` branch.
4. In GitHub, open **Settings > Pages**.
5. Set **Source** to `Deploy from a branch`, choose `main`, then choose `/root`.
6. Your website will be available at `https://yourusername.github.io/`.

If you want a custom domain later, add it in **Settings > Pages > Custom domain** and follow GitHub's DNS instructions.
